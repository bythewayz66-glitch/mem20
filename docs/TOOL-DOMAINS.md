response by `scripts/surface_manifest.py`, with every tool name and domain

Regenerate and verify:

```bash
python3 scripts/surface_manifest.py --write
python3 scripts/surface_manifest.py --check   # CI: fail on drift
```

## How the numbers are derived

| step | value | why |
|---|---:|---|
| live `tools/list` | **487** | the wire surface a client actually receives |
| AST catalog, wired | **487** | `mt.Tool(...)` declarations in modules the server inherits |
| AST declarations, unwired | 19 | declared in source but not registered by any inherited mixin |
| domains | **129** | distinct owning modules after the documented folds |
| names only in `tools/list` | 0 | must be 0 |
| names only in the AST catalog | 0 | must be 0 |

The two collections are compared as sets, so a count can only agree if the
same tools are present. A non-empty symmetric difference aborts generation.
