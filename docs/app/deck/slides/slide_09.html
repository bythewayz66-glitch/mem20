08 / THE FINDING WE DID NOT GO LOOKING FOR
Reranking is inverting our quality
The production path runs hybrid with a cross-encoder reranker. Scoring it against the same path with the reranker switched off is the single most useful number in this report — and it does not flatter the product.
HYBRID — RERANK ON (production)
0.167
adversarial hit rate
MRR 0.167
p50 168.5 ms
HYBRID — RERANK OFF
0.650
adversarial hit rate
MRR 0.633
p50 25.6 ms — 6.6× faster
SWITCHING THE RERANKER OFF IS WORTH, ON THIS CORPUS:
+0.483 hit rate  ·  +0.466 MRR  ·  −143 ms p50
01
It is not one query class.
Adversarial 0.167→0.650, adversarial_hard 0.050→0.625, multi_hop 0.533→1.000. Three of three.
02
Direct queries are unaffected.
Both score 1.000 / 0.978 vs 0.979. The damage is confined to exactly the class we sell on.
03
So it is a bug, not a trade-off.
We are paying 6.6× latency for a 48-point regression. That is a config to fix, not a cost to accept.
The report's own rerank_off_comparison field is null — the on/off contrast was never computed as an A/B, only as two standalone modes. Reading them side by side is our analysis, not the harness's claim, and the harness says so in rerank_off_note.
