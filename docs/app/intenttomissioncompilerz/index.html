RM-031 Intent-to-Mission Compiler

Subsystem: mem20intenttomissioncompilerz (#330). Converts a human objective into an executable mission with dependencies, roles, and completion criteria. Includes real integrations with intent parsing, goal scheduling, priority collision resolution, skill/role analysis, reversible execution planning, and self-healing mission planning.

Run (CLI)

cd /opt/mem20
PYTHONPATH=/opt/mem20 .venv/bin/python -m mem20intenttomissioncompilerz execute \
  '{"goal":"design and ship feature","parts":["design","build","test"],"agents":["planner","engineer"]}'

Returns a live mission plan: mission_id, ordered steps with depends_on/role/completion_criteria/status, dependencies, validation/progress, and 6 peer signal reports (fail-open, honest ok/error).

Serve web console/API

cd /opt/mem20
PYTHONPATH=/opt/mem20 .venv/bin/python -m mem20intenttomissioncompilerz serve --port 8831

Starts the runtime HTTP console/API (versioned SQLite WAL state, events/jobs, metrics/health routes as provided by the runtime).

Conformance

cd /opt/mem20
PYTHONPATH=/opt/mem20 .venv/bin/python scripts/renovation/conformance.py mem20intenttomissioncompilerz
