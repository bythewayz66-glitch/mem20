mem20labz — Laboratory Runtime (#331)

1st-class control plane for 10 member lab subsystems: registry/discovery, health probes, simulation orchestration, 6-peer ecosystem signals, durable SQLite WAL run history, CLI, JSON/HTTP API, and served web frontend.

CLI

cd /opt/mem20
PYTHONPATH=/opt/mem20 .venv/bin/python -m mem20labz --members
PYTHONPATH=/opt/mem20 .venv/bin/python -m mem20labz status
PYTHONPATH=/opt/mem20 .venv/bin/python -m mem20labz signals
PYTHONPATH=/opt/mem20 .venv/bin/python -m mem20labz serve --port 8841

API/frontend routes: /, /api/status, /api/registry, /api/probe, /api/simulate, /api/signals, /api/history, /health.
