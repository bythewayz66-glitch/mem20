# Spec authority paths (#14 / #15)

No personal absolute path as a required default. Use `specs/`, `Path.home()`, or env vars.

| Variable | Purpose |
|----------|--------|
| `MEM20_ENGINE_PATH` | Repo / engine root |
| `MEM20_SPEC_SOURCE` | Spec authority (default `specs`) |
| `UNITY_EDITOR` | Unity binary |
| `MEM20_STORE_PATH` | Memory store |
| `MEM20_PACKAGE` | owebz package path |
| `MEM20_AUDIT_OUT` | Audit output path |
