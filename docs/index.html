A memory that can prove what it knows.

The one rule

Most agent memory is a single undifferentiated pile: a guess and a fact look identical once they are both embedded. mem20 keeps them apart at the storage layer, so the distinction survives retrieval, summarisation and time.

grounded What was observed

Written from a real event, a real document, a real tool result. Carries its provenance and can be re-checked against the source. This is the only class of memory mem20 will assert as true.

simulated What was inferred

Written by a model reasoning about what might be the case. Useful, and never presented as fact. It stays labelled, so a later reader — human or agent — can tell which is which.

Three layers, in dependency order

A durable substrate, a protocol surface, and a large estate of independently packaged capability modules.

Layer 01

Memory engine

Global memory, ledger and vector store. The durable substrate — everything else is a view onto it.

Layer 02

MCP server

Exposes the engine and the wider estate as MCP tools over stdio, with an HTTP health/metrics endpoint.

Layer 03

Subsystems

Independently packaged capability modules, each with its own pyproject.toml and its own tests.

Run it

From a git checkout. The server starts, logs its health endpoint, and speaks JSON-RPC 2.0 over stdio.

# clone and install
git clone https://github.com/bythewayz66-glitch/mem20.git
cd mem20
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# start the MCP server
MEM20_STORE_PATH="$HOME/.mem20/store" .venv/bin/python mcp/mcp_server.py
