Two series about memory you can prove.

Why these two, and not a brochure

A memory product is hard to feel from a feature list. A comic can show a character discovering that a memory was never theirs. A chronicle can show, day by day, a system that says out loud which of its own statements it can stand behind. Same thesis, two formats, one public home.

Property 01

The Comicbook Artist

Long-form sequential art. Canon, character and page order are owned by the Comicbook Artist; this site is the reader-facing home and the index of what has shipped.

Property 02

Mem20-naration's Chronicles

Daily installments, written by Mem20-naration. Every entry carries an origin tag so a reader can never mistake a hypothesis for a record.

Shared

One canon, one ledger

Both series draw from the same source of truth and both publish a machine-readable feed, so later tooling — readers, archives, analytics — never has to scrape HTML.
