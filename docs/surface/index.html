mem20 4.0 · the tool surface

487 tools. 129 domains. One auditable surface.

This is the whole MCP surface of mem20 4.0, not a selection. Every tool below is registered on the server, reachable over JSON-RPC tools/list, and traceable to the module that declares it. The count is generated from the wire response and cross-checked against the source tree — if the two ever disagree, the build fails rather than publishing a number.

How the number is derived

Two independent collections are compared as sets. A count can only agree if the same tool names are present in both, so the published figure is a measurement rather than a claim. A non-empty symmetric difference aborts generation.
