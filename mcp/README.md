## Tool-surface admission control (`surface.py`)

A tool is on the MCP surface because the estate's own rules admit it, not
because somebody added it to a list. `surface.py` runs five checks and every one
of them is delegated to the module that already owns that rule:

| check | delegated to | refuses when |
|---|---|---|
| `name` | `mem20ops.clicheck.classify_naming` | the name is generic or classified `other` |
| `body` | `mem20verify.linters.noop_bodies` | the handler body is only `pass`, or no source was supplied |
| `uses` | `mem20liez.gates.check_prohibited_uses` | a declared use is on the prohibited list |
| `validity` | `mem20temporaldatabasefabricz.temporal.interval.contains` | the instant is outside the declared window |
| `signal` | `mem20ircz.filter.classify` | every declared wire line is protocol noise |

All five checks run, so a refusal reports every reason at once.

### Run it

```bash
cd mcp
printf 'def mem20_search(q):\n    return q\n' > /tmp/tool_ok.py
python3 cli.py admit mem20_search --source /tmp/tool_ok.py
```
