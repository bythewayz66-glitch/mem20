# mem20autoz — autonomous / auto systems runtime

Unified organ for every former top-level package whose name contains **auto**
(except this package itself). Those packages are **absorbed here** and removed
from the monorepo root.

## Absorbed members

See `MEMBERS` in `mem20autoz/__init__.py` and `ABSORBED.md`.

Includes autonomous crews, autopilots, autogenerated prototype path, autouez,
personal automation canvas, and protocol autodiscovery.

## CLI

```bash
mem20autoz --version
mem20autoz --members
```

## Status

Consolidation package: single product surface for auto/autonomous systems.
Root `mem20*auto*` member directories are deleted after this merge.
