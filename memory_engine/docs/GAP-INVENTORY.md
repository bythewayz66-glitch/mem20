## Defects found (recorded, not silently fixed)

### D1 — Version drift between `pyproject.toml` and `VERSION`
- `pyproject.toml:7` → `version = "3.0.0"`
- `VERSION` → `3.1.2`
- **Impact:** a wheel built from this tree is labelled 3.0.0 and will not upgrade
  over an installed 3.1.x. Two releases of fixes are invisible to any package
  manager.
- **Status:** recorded. Fix belongs in the packaging increment (P9), not M0.

### D2 — `memory.py.broken` committed at repo root
- 19,858 B, tracked in git at the repository root.
- **Impact:** ships in every sdist/wheel that globs the root; a reader cannot
  tell which file is live.
- **Status:** recorded. Removal needs owner sign-off (it is a tracked file).

### D3 — `memory_engine/tests/test_pii_non_destructive.py` fails to collect
```
ImportError: cannot import name '_detect_only' from 'memory' (/workspace/mem20/memory.py)
```
- The test imports `_detect_only` from the repo-root `memory.py` shim, which
  re-exports only `_load_ledger`, `_append_ledger`, `_scrub_secrets`,
  `SUPERSEDED`, `main` (`memory.py:10-16`).
- **Impact:** one of five test files in the subsystem cannot run at all. The
  secret-detection regression suite is effectively disabled.
- **Status:** recorded. Fix is a one-line addition to the shim's re-export list;
  deferred to the test-hardening increment so M0 stays a pure additive seam.

### D4 — Two tests fail without optional native deps
```
FAILED test_fact_fiction_labeling.py::...::test_recall_semantic_returns_the_label
FAILED test_fact_fiction_labeling.py::...::test_recall_hybrid_returns_the_label
```
- Both require `faiss` + `sentence-transformers`, which are not installed in
  this environment. They are not marked `@pytest.mark.integration` despite
  `pytest.ini` declaring that marker.
- **Impact:** CI cannot distinguish "broken" from "dependency absent".
- **Status:** recorded. Fix is marker hygiene, deferred.

### D5 — `tests/test_retrieval_graph.py` and `tests/test_rerank_no_silent_noop.py` fail at baseline
- Verified by `git stash -u` then re-running: **7 failed / 20 passed** before M0
  and **7 failed / 20 passed** after. Identical. Not caused by M0.
- Root cause is the same missing `faiss`/`sentence-transformers`.
- **Status:** recorded as pre-existing, out of scope for M0.

### D6 — `mcp/` directory shadows the installed MCP SDK
- A local `mcp/` package at repo root shadows the PyPI `mcp` package for any
  process whose cwd is the repo root.
- **Status:** recorded. Out of scope for memory_engine.
