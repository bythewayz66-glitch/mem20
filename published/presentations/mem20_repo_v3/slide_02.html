THE PROBLEM
Agents forget.
And they cannot prove what they remember.
Every memory product today sells recall quality. Almost none can answer the question a compliance reviewer actually asks: where did this fact come from, and was it ever real?
🗑
Recall decays silently
An index drifts from its ledger and search returns zero results while reporting success. The caller cannot tell “nothing matches” from “your index is stale.”
🧪
Hypotheses become facts
A model’s guess gets written into the same store as a user’s statement, and the next retrieval has no way to separate them.
📜
No audit trail
No append-only record of how a memory entered the system, what promoted it, or who attested to it — so there is nothing to hand a regulator.
The wedge: mem20 does not win on recall quality. It wins on recall trustworthiness — a memory system that tells you when it does not know.
