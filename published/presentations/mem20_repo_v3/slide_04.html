HOW IT WORKS
The separation is enforced in code
1 · Transport
An MCP client connects over stdio to mcp/mcp_server.py. JSON-RPC 2.0, 270 tools, 27 domains.
2 · Two partitions that never mix
Grounded holds observations, user statements and events. Simulated holds counterfactuals, hypotheses and model output.
3 · Write-path guards
remember() refuses any record not tagged origin="grounded"; both indexes call _assert_grounded() on every write and raise immediately.
4 · Evidence-based promotion
Moving out of simulated requires a resolved prediction or an external verifier’s attestation. A boolean flag and a free-text note are refused.
The point is not the diagram — it is that a simulated record reaching an index raises at write time instead of being discovered later by an audit.
