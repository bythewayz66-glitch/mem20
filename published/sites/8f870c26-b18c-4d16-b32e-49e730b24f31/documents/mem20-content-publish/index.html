Guardrails that hold across every asset

  • No LoCoMo / LongMemEval claim. No numeric retrieval benchmark is published, and none is implied.
  • The adversarial-retrieval weakness is disclosed wherever limits are discussed.
  • Promotion is described as evidence-based with an append-only audit trail — never tamper-proof or unfakeable.
  • No competitor disparagement. Third-party figures are vendor self-reported and never used as a baseline.

Open blockers

  • The registry package is unpublished — PyPI 404; every asset ships the source install.
  • Posting is manual — there is no HN / X / GitHub / MCP-directory account wired up; all copy is paste-ready.
  • The /sites/ pages are token-gated — they return 403 to anonymous visitors. The public-facing URL is GitHub Pages.
