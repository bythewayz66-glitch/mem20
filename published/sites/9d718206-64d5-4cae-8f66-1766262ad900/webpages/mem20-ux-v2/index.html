03 / PUBLISHPublish path & constraint

The program constraint is that all work is published to the Sidney server via ssh/sftp/rsync and passes through gabe. Applied honestly to this deliverable: this sandbox holds the asset files and publishes them to their permanent artifact URLs (the links on this page); the Sidney-side placement is a handoff, not something these assets can perform themselves.

Verified constraint, not an assumption: this run has no SSH host, key, or credential for Sidney or gabe in the environment (checked ~/.ssh and the environment). So the assets were produced and published to their permanent URLs here, and the Sidney/rsync placement is listed as an open dependency in the handoff spec — the same blocker Server Builder reported for the Sidney deployment.
