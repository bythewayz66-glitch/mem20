# mem20 core runtime (required for full function)
# Pinned to versions verified in the build venv; loosen the lower bounds if needed.

# aiohttp and mcp-types are imported at MODULE SCOPE, not lazily, by modules the
# MCP server loads before it can serve a single request:
#   aiohttp      -> mcp/tools/a2a_tools.py:19    (the a2a_* tools)
#   mcp-types    -> mcp/server.py:48, mcp/tools/*.py (`import mcp_types as mt`)
# Neither ships as a dependency of `mcp`, so a clean
# `pip install -r requirements.txt` that omits them cannot boot the server:
# a2a_tools.py fails on `import aiohttp` before `tools/` is even reachable.

# FastAPI/Starlette compatibility pin (issue #179/#180).
#
# fastapi 0.115.12 calls `routing.APIRouter(on_startup=..., on_shutdown=...)`,
# which Starlette removed in 1.0. An unpinned install resolves starlette 1.7.0
# and every FastAPI app in the estate fails at import with
#
#     TypeError: Router.__init__() got an unexpected keyword argument 'on_startup'
#
# which aborted collection for mem20messenger and mem20mktz. Pinned below the
# release that removed the argument; raise this only together with a fastapi
# upgrade that stops passing it.
fastapi>=0.115,<0.116
starlette>=0.40,<0.42
