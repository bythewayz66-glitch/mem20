# Essential Game Maker Pipelines

## Overview
Core pipelines for integrating mem20 with GameMaker projects for persistent agent memory and world simulation.

## Pipelines
1. **Memory Integration Pipeline** - Connect GameMaker to mem20 MCP server
2. **World State Synchronization** - Sync game state with mem20 world model
3. **Agent Behavior Pipeline** - Drive agent actions from mem20 memories
4. **Persistence Pipeline** - Save/load game state through mem20
5. **Event Logging Pipeline** - Log game events to mem20 ledger
6. **Knowledge Extraction Pipeline** - Extract game knowledge into mem20 memory
7. **Planning Pipeline** - Use mem20 for agent planning and decision making
8. **Dialogue Pipeline** - Context-aware dialogue using mem20 memories
9. **Quest Pipeline** - Quest tracking with mem20
10. **Debug Pipeline** - Memory inspection and debugging tools
